# News Search

## 使用场景

当用户要求搜索最新新闻、今日资讯、时事动态或实时热榜时使用。

## 执行步骤

1. 使用 `search` 查找与用户主题和时间范围相符的候选来源。
2. 搜索结果只是线索；使用 `fetch_content` 获取最可能包含具体事实的正文页面。
3. 区分新闻正文、实时榜单与网站首页。正文不足时尝试其他候选来源。
4. 只根据真实正文整理标题、简短摘要、来源和用户要求的其他字段。

## 注意事项

- 不直接把候选 URL 列表作为最终回答。
- 不得生成“标题1”“标题2”等占位内容。
- 不得虚构实时新闻、热搜条目、来源或发布时间。
- 无法取得有效正文时，应说明失败原因和已获得的信息边界。
