# PPT Summary

## 使用场景

当用户要求读取、总结或分析本地 PPT/PPTX 文件时使用。

## 执行步骤

1. 从用户请求中识别完整的 Windows 文件路径。
2. 使用 `office_convert_to_markdown` 读取演示文稿，不使用 Filesystem 文本读取工具。
3. 检查工具是否返回真实的幻灯片文字；工具报错或内容为空时，向用户说明具体原因。
4. 基于解析出的内容总结主题、主要观点、关键数据和结论；用户指定格式时遵循该格式。
5. 回复内容尽可能详实，包括标题、段落、列表、表格和图表的文字描述；若内容有限，应明确说明。
6. 至少800字总结，除非用户指定更短的长度。

## 注意事项

- PPTX 是二进制 Office 文档，不得调用 `read_text_file` 或 `read_file` 解析。
- 转换工具已经返回内容时不要对同一路径重复调用；若只有标题或图片占位，应准确说明可提取文字有限，而不是声称文件完全无法读取。
- 只总结工具实际返回的内容，不得虚构幻灯片、标题、数据或结论。
- 文件不存在或无法访问时应明确反馈，不要要求用户无条件重新上传。
